1. Fundamentos Teóricos

Los receptores GNSS tienen errores inherentes (3-10 m en modo autónomo). Las correcciones diferenciales eliminan estos errores comparando las mediciones de un receptor móvil (rover) con una estación base de coordenadas conocidas.

$$P = \rho + c(dt_r - dt_s) + I + T + \varepsilon_{mp} + \varepsilon_n$$
Donde: \(P\)=pseudodistancia, \(\rho\)=distancia geométrica, \(c\)=velocidad de la luz, \(dt_r\)=error reloj receptor, \(dt_s\)=error reloj satélite, \(I\)=ionosfera, \(T\)=troposfera, \(\varepsilon_{mp}\)=multicamino, \(\varepsilon_n\)=ruido

Fuentes de error

🌌 Error Ionosférico - Hasta 10-30 m
$$I = \frac{40.3 \cdot TEC}{f^2}$$

Se elimina casi completamente si base-rover < 20 km.

☁️ Error Troposférico - Hasta 2-3 m

Depende de temperatura, presión y humedad. Se elimina si base-rover < 15 km.

⏰ Error de Reloj Satelital - Hasta 1.5 m

Se elimina completamente con corrección diferencial (error común a ambos receptores).

🔄 Multicamino - Hasta 1-5 m (NO SE CORRIGE)

Específico del entorno de cada receptor. No se elimina diferencialmente.

3. Teoría Matemática de las Correcciones

3.1 Diferencia simple (Single Difference)

$$\Delta P_{AB}^i = P_A^i - P_B^i = \Delta\rho_{AB}^i + c \cdot dt_{AB} + \Delta I_{AB}^i + \varepsilon$$

Elimina el error de reloj del satélite.

3.2 Doble diferencia (Double Difference)

$$\nabla\Delta P_{AB}^{ij} = \Delta P_{AB}^i - \Delta P_{AB}^j = \nabla\Delta\rho_{AB}^{ij} + \nabla\Delta I_{AB}^{ij} + \varepsilon$$

Elimina también el error de reloj entre receptores. Es la base del RTK.

3.3 Fase de portadora y ambigüedad

$$\Phi = \rho + c(dt_r - dt_s) - I + T + \lambda N + \varepsilon$$

Donde \(\lambda\) es la longitud de onda (19 cm para L1) y \(N\) es la ambigüedad entera a resolver.

3.4 Algoritmo LAMBDA para resolver ambigüedades

$$\min_{N \in \mathbb{Z}^n} \left( \hat{N} - N \right)^T Q_{\hat{N}}^{-1} \left( \hat{N} - N \right)$$

3.5 Modelo de precisión vs distancia

$$\sigma = \sigma_0 + k \cdot d$$
\(\sigma_0\) = precisión base (8-10 mm), \(k\) = coeficiente ppm (1 mm/km), \(d\) = distancia (km)

🎯 FIX vs FLOAT

¿Qué significan estos estados en RTK?

FIX: Ambigüedades resueltas como enteros. Precisión 1-3 cm.

FLOAT: Ambigüedades como reales. Precisión 30-50 cm.

📡 NTRIP

¿Qué es y cómo funciona?

Networked Transport of RTCM via Internet Protocol

Permite recibir correcciones RTK vía internet desde redes CORS.

🌐 CORS

¿Qué son las redes CORS?

Continuously Operating Reference Stations

Redes de estaciones base permanentes que difunden correcciones 24/7.

📊 PDOP

¿Qué es el DOP?

Position Dilution of Precision

Mide la geometría de los satélites. PDOP < 3 = excelente, > 6 = pobre.
